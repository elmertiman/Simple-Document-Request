# Simple Document Request WordPress Plugin

A WooCommerce plugin that allows customers to request authenticity documents for products via OTP (One-Time Password) verification.

## Features

- **OTP Verification**: Customers can request an authenticity document by entering their email and verifying with a one-time password
- **Single-Use OTP**: Each OTP code can only be used once for security
- **Email Notifications**: Automatic email sending with OTP codes
- **PDF Email Delivery**: Automatically sends the PDF document as an email attachment after successful OTP verification (no in-browser viewing)
- **Media Library Integration**: Easy PDF upload directly from WordPress media library
- **Advanced Admin Dashboard**: View, search, sort, and filter all authentication requests with AJAX-driven interface
- **Admin Notifications**: Receive email alerts for new authenticity requests
- **Product Integration**: Seamlessly integrates with WooCommerce product pages (button only shows if PDF is configured)
- **Database Storage**: All email addresses and requests are saved in the database
- **Spam Folder Reminder**: Success message reminds users to check junk/spam folders

## Installation

1. Upload the `simple-document-request` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Ensure WooCommerce is installed and active

## Setup

### 1. Configure Your Site Logo (Optional but Recommended)

1. Go to **Appearance** → **Customize** → **Site Identity**
2. Click **"Select logo"** to upload your logo
3. Save changes

Your logo will now appear in all plugin emails!

### 2. Configure Products

1. Go to **Products** → Edit a product
2. In the **General** tab of the product data section, find **"Authenticity PDF"** field
3. Click **"Upload PDF"** button to select a PDF from the media library, or manually enter a PDF URL
4. Save the product

**Note**: The "Click Here For Proof of Authenticity" button will only appear on products that have a PDF configured.

## Usage

### For Customers

1. Visit a WooCommerce product page (with configured authenticity PDF)
2. Click the **"Click Here For Proof of Authenticity"** button
3. Enter your email address and click **"Send OTP Code"**
4. Check your email for the OTP code
5. Enter the OTP code in the modal
6. Receive the authenticity PDF document via email as an attachment
7. **Important**: Check both your inbox and junk/spam folder for the document

### For Administrators

1. Go to **Document Requests** in the WordPress admin menu
2. **Search Functionality**: Search by email, product ID, or OTP code
3. **Sort Columns**: Click any column header to sort (ID, Product, Email, Status, dates)
4. **Filter by Status**: Filter requests by All, Verified, or Pending
5. View detailed information for each request:
   - Product name (clickable to edit product)
   - Customer email
   - OTP code
   - Verification status (color-coded)
   - Request and verification timestamps
6. **Real-time Updates**: All search and sort operations happen instantly via AJAX

## Email Functionality

The plugin sends three types of emails, all featuring your website logo for professional branding:

1. **OTP Code Email** - Sent to customer with verification code
2. **Admin Notification** - Sent to WordPress admin when new request is made
3. **Authenticity Document** - Sent to customer with PDF attachment after successful verification

### Email Branding
- Automatically displays your website logo at the top of all emails
- Uses the custom logo set in **Appearance → Customize → Site Identity**
- Falls back to site icon if no custom logo is set
- Professional presentation with responsive sizing

### PDF Attachment Handling

- Supports local WordPress media library files
- Supports external PDF URLs (automatically downloaded and attached)
- Temporary files are cleaned up automatically after sending
- Falls back to email without attachment if PDF is unavailable

## Requirements

- WordPress 5.0 or higher
- PHP 7.2 or higher
- WooCommerce 3.0 or higher
- PHP `allow_url_fopen` enabled (for external PDF downloads)

## Database

The plugin creates a custom table `wp_sdr_authenticity_requests` to store:
- Product ID
- Email address
- OTP code
- Usage status (used/unused)
- Timestamps

## Security

- OTP codes are single-use only
- Nonce verification for all AJAX requests
- Email and input sanitization
- SQL injection prevention using prepared statements
