# Simple Document Request WordPress Plugin

A WooCommerce plugin that allows customers to request authenticity documents for products via OTP (One-Time Password) verification.

## Features

- **OTP Verification**: Customers can request an authenticity document by entering their email and verifying with a one-time password
- **Single-Use OTP**: Each OTP code can only be used once for security
- **Email Notifications**: Automatic email sending with OTP codes
- **PDF Display**: Shows authenticity PDF document after successful verification
- **Admin Dashboard**: View all authentication requests and email addresses
- **Product Integration**: Seamlessly integrates with WooCommerce product pages
- **Database Storage**: All email addresses and requests are saved in the database

## Installation

1. Upload the `simple-document-request` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Ensure WooCommerce is installed and active

## Setup

1. Go to **Products** → Edit a product
2. In the product data section, find **"Authenticity PDF URL"** field
3. Enter the URL to your PDF file (can be uploaded to Media Library or external URL)
4. Save the product

## Usage

### For Customers

1. Visit a WooCommerce product page
2. Click the **"Click Here For Proof of Authenticity"** button
3. Enter your email address and click **"Send OTP Code"**
4. Check your email for the OTP code
5. Enter the OTP code in the modal
6. View the authenticity document PDF after verification

### For Administrators

1. Go to **Document Requests** in the WordPress admin menu
2. View all authentication requests including:
   - Product name
   - Customer email
   - OTP code
   - Verification status
   - Request and verification timestamps

## Requirements

- WordPress 5.0 or higher
- PHP 7.2 or higher
- WooCommerce 3.0 or higher

## Database

The plugin creates a custom table `wp_sdr_authenticity_requests` to store:
- Product ID
- Email address
- OTP code
- Usage status (used/unused)
- Timestamps

## Security

- OTP codes are single-use only
- Nonce verification for all AJAX requests
- Email and input sanitization
- SQL injection prevention using prepared statements
